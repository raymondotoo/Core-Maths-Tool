# Chapter 21: Quadratic Equations

## 21.1 Introduction to Quadratic Equations

A **quadratic equation** has the form:
$$ax^2 + bx + c = 0$$

where a ≠ 0.

The solutions are called **roots** of the equation.

---

## 21.2 Solving by Factorization

If a quadratic can be factored, set each factor equal to zero.

### Example 21.1: Simple Factorization
#### Problem
Solve x² - 5x + 6 = 0

#### Solution
Factorize:
(x - 2)(x - 3) = 0

Set each factor to zero:
x - 2 = 0 or x - 3 = 0
**x = 2 or x = 3**

### Example 21.2: Leading Coefficient ≠ 1
#### Problem
Solve 2x² + 5x - 3 = 0

#### Solution
Factorize:
(2x - 1)(x + 3) = 0

2x - 1 = 0 or x + 3 = 0
**x = ½ or x = -3**

### Example 21.3: Difference of Squares
#### Problem
Solve x² - 16 = 0

#### Solution
x² = 16
x = ±4

**x = 4 or x = -4**

---

## 21.3 Completing the Square

### Method:
1. Move constant to right side
2. Add (b/2a)² to both sides
3. Factor the perfect square
4. Take square root of both sides

### Example 21.4: Completing the Square
#### Problem
Solve x² + 6x - 7 = 0 by completing the square.

#### Solution
x² + 6x = 7

Add (6/2)² = 9 to both sides:
x² + 6x + 9 = 7 + 9
(x + 3)² = 16

Take square root:
x + 3 = ±4

x = -3 + 4 = 1 or x = -3 - 4 = -7

**x = 1 or x = -7**

### Example 21.5: Coefficient ≠ 1
#### Problem
Solve 2x² - 8x - 10 = 0 by completing the square.

#### Solution
Divide by 2:
x² - 4x - 5 = 0
x² - 4x = 5

Add (-4/2)² = 4:
x² - 4x + 4 = 9
(x - 2)² = 9
x - 2 = ±3

**x = 5 or x = -1**

## 21.4 The Quadratic Formula

For ax² + bx + c = 0:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

### Example 21.6: Using the Formula
#### Problem
Solve 2x² + 3x - 5 = 0

#### Solution
a = 2, b = 3, c = -5

$$x = \frac{-3 \pm \sqrt{9 - 4(2)(-5)}}{2(2)}$$
$$x = \frac{-3 \pm \sqrt{9 + 40}}{4}$$
$$x = \frac{-3 \pm \sqrt{49}}{4}$$
$$x = \frac{-3 \pm 7}{4}$$

x = (-3 + 7)/4 = 1 or x = (-3 - 7)/4 = -2.5

**x = 1 or x = -2.5**

### Example 21.7: Irrational Roots
#### Problem
Solve x² - 4x + 1 = 0 (leave answer in surd form)

#### Solution
$$x = \frac{4 \pm \sqrt{16 - 4}}{2}$$
$$x = \frac{4 \pm \sqrt{12}}{2}$$
$$x = \frac{4 \pm 2\sqrt{3}}{2}$$

**x = 2 + √3 or x = 2 - √3**

---

## 21.5 The Discriminant

The **discriminant** is: D = b² - 4ac

| Discriminant | Nature of Roots |
|--------------|-----------------|
| D > 0 | Two distinct real roots |
| D = 0 | One repeated (equal) root |
| D < 0 | No real roots (complex) |

### Example 21.8: Finding Nature of Roots
#### Problem
Determine the nature of roots of 3x² - 5x + 4 = 0

#### Solution
D = b² - 4ac = (-5)² - 4(3)(4)
  = 25 - 48
  = -23

Since D < 0: **No real roots**

### Example 21.9: Equal Roots
#### Problem
Find k if x² + kx + 9 = 0 has equal roots.

#### Solution
For equal roots: b² - 4ac = 0
k² - 4(1)(9) = 0
k² = 36
**k = ±6**

---

## 21.6 Sum and Product of Roots

For roots α and β of ax² + bx + c = 0:

- **Sum**: α + β = -b/a
- **Product**: αβ = c/a

### Example 21.10: Finding Sum and Product
#### Problem
Without solving, find the sum and product of roots of 2x² - 7x + 3 = 0

#### Solution
Sum = -b/a = -(-7)/2 = **7/2**
Product = c/a = 3/2 = **3/2**

### Example 21.11: Forming Equation from Roots
#### Problem
Form a quadratic equation with roots 3 and -5.

#### Solution
Sum = 3 + (-5) = -2
Product = 3 × (-5) = -15

Equation: x² - (sum)x + (product) = 0
**x² + 2x - 15 = 0**

## 21.7 Word Problems

### Example 21.12: Area Problem
#### Problem
A rectangle has length 5 cm more than its width. If the area is 84 cm², find the dimensions.

#### Solution
Let width = x cm
Length = (x + 5) cm
Area: x(x + 5) = 84
x² + 5x - 84 = 0
(x + 12)(x - 7) = 0
x = -12 or x = 7

Since width must be positive: x = 7

**Width = 7 cm, Length = 12 cm**

### Example 21.13: Number Problem
#### Problem
The sum of a number and its square is 56. Find the number.

#### Solution
Let the number = x
x + x² = 56
x² + x - 56 = 0
(x + 8)(x - 7) = 0
x = -8 or x = 7

**The number is 7 or -8**

---

## 21.8 Equations Reducible to Quadratics

### Example 21.14: Substitution Method
#### Problem
Solve x⁴ - 13x² + 36 = 0

#### Solution
Let y = x²
y² - 13y + 36 = 0
(y - 4)(y - 9) = 0
y = 4 or y = 9

Since y = x²:
x² = 4 → x = ±2
x² = 9 → x = ±3

**x = ±2 or x = ±3**
