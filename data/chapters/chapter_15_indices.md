# Chapter 15: Indices (Exponents)

## 15.1 Introduction to Indices

An **index** (plural: indices) or **exponent** shows how many times a base is multiplied by itself.

$$a^n = \underbrace{a \times a \times a \times ... \times a}_{n \text{ times}}$$

### Examples:
- 2³ = 2 × 2 × 2 = 8
- 5² = 5 × 5 = 25
- 10⁴ = 10,000

---

## 15.2 Laws of Indices

| Law | Rule | Example |
|-----|------|---------|
| Multiplication | aᵐ × aⁿ = aᵐ⁺ⁿ | 2³ × 2⁴ = 2⁷ |
| Division | aᵐ ÷ aⁿ = aᵐ⁻ⁿ | 5⁶ ÷ 5² = 5⁴ |
| Power of Power | (aᵐ)ⁿ = aᵐⁿ | (3²)⁴ = 3⁸ |
| Zero Index | a⁰ = 1 (a ≠ 0) | 7⁰ = 1 |
| Negative Index | a⁻ⁿ = 1/aⁿ | 2⁻³ = 1/8 |
| Fractional Index | a^(m/n) = ⁿ√(aᵐ) | 8^(2/3) = 4 |
| Distribution | (ab)ⁿ = aⁿbⁿ | (2×3)² = 4×9 = 36 |

---

## 15.3 Multiplication Law

### Example 15.1: Same Base Multiplication
#### Problem
Simplify 3⁴ × 3⁵

#### Solution
3⁴ × 3⁵ = 3⁴⁺⁵ = **3⁹**

### Example 15.2: With Coefficients
#### Problem
Simplify 2x³ × 5x⁴

#### Solution
= (2 × 5) × (x³ × x⁴)
= 10 × x³⁺⁴
= **10x⁷**

---

## 15.4 Division Law

### Example 15.3: Same Base Division
#### Problem
Simplify $$\frac{a^8}{a^3}$$

#### Solution
$$\frac{a^8}{a^3} = a^{8-3} = \mathbf{a^5}$$

### Example 15.4: With Coefficients
#### Problem
Simplify $$\frac{12x^6}{4x^2}$$

#### Solution
$$= \frac{12}{4} \times \frac{x^6}{x^2}$$
$$= 3 \times x^{6-2}$$
$$= \mathbf{3x^4}$$

---

## 15.5 Power of a Power

### Example 15.5: Power of Power
#### Problem
Simplify (2³)⁴

#### Solution
(2³)⁴ = 2³ˣ⁴ = **2¹²**

### Example 15.6: Combined Expression
#### Problem
Simplify (x²y³)⁴

#### Solution
= x²ˣ⁴ × y³ˣ⁴
= **x⁸y¹²**

---

## 15.6 Zero and Negative Indices

### Example 15.7: Zero Index
#### Problem
Evaluate 5⁰ + 3⁰ - 2⁰

#### Solution
= 1 + 1 - 1
= **1**

### Example 15.8: Negative Index
#### Problem
Simplify 4⁻²

#### Solution
$$4^{-2} = \frac{1}{4^2} = \frac{1}{16} = \mathbf{\frac{1}{16}}$$

### Example 15.9: Converting Negative to Positive
#### Problem
Write $$\frac{3}{x^{-4}}$$ with positive indices

#### Solution
$$\frac{3}{x^{-4}} = 3 \times x^4 = \mathbf{3x^4}$$

---

## 15.7 Fractional Indices

$$a^{\frac{1}{n}} = \sqrt[n]{a}$$ (nth root of a)

$$a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$$

### Example 15.10: Square Root as Index
#### Problem
Evaluate 25^(1/2)

#### Solution
$$25^{\frac{1}{2}} = \sqrt{25} = \mathbf{5}$$

### Example 15.11: Cube Root
#### Problem
Evaluate 27^(1/3)

#### Solution
$$27^{\frac{1}{3}} = \sqrt[3]{27} = \mathbf{3}$$

### Example 15.12: Combined Fractional Index
#### Problem
Evaluate 8^(2/3)

#### Solution
$$8^{\frac{2}{3}} = (\sqrt[3]{8})^2 = 2^2 = \mathbf{4}$$

Alternative: $$8^{\frac{2}{3}} = \sqrt[3]{8^2} = \sqrt[3]{64} = 4$$

---

## 15.8 Simplifying Complex Expressions

### Example 15.13: Mixed Expression
#### Problem
Simplify $$\frac{2^5 \times 2^{-3}}{2^4}$$

#### Solution
$$= \frac{2^{5+(-3)}}{2^4}$$
$$= \frac{2^2}{2^4}$$
$$= 2^{2-4}$$
$$= 2^{-2}$$
$$= \mathbf{\frac{1}{4}}$$

### Example 15.14: Variables
#### Problem
Simplify $$\frac{x^3y^{-2}}{x^{-1}y^4}$$

#### Solution
$$= x^{3-(-1)} \times y^{-2-4}$$
$$= x^4 \times y^{-6}$$
$$= \mathbf{\frac{x^4}{y^6}}$$

---

## 15.9 Solving Equations with Indices

### Example 15.15: Same Base
#### Problem
Solve 2^x = 32

#### Solution
32 = 2⁵
2^x = 2⁵
**x = 5**

### Example 15.16: Different Forms
#### Problem
Solve 9^x = 27

#### Solution
Express in same base (3):
(3²)^x = 3³
3^(2x) = 3³
2x = 3
**x = 3/2**

### Example 15.17: Fractional Answer
#### Problem
Solve 4^x = 8

#### Solution
Express in base 2:
(2²)^x = 2³
2^(2x) = 2³
2x = 3
**x = 3/2**

---

## 15.10 Standard Form

Scientific notation: a × 10ⁿ where 1 ≤ a < 10

### Example 15.18: To Standard Form
#### Problem
Write 4,500,000 in standard form

#### Solution
4,500,000 = 4.5 × 10⁶

**4.5 × 10⁶**

### Example 15.19: From Standard Form
#### Problem
Write 3.72 × 10⁻⁴ as a decimal

#### Solution
3.72 × 10⁻⁴ = **0.000372**
