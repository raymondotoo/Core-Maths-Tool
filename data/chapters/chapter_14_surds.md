# Chapter 14: Surds

## 14.1 Introduction to Surds

A **surd** is an irrational root that cannot be simplified to a rational number.

Examples of surds: √2, √3, √5, ∛7

Non-surds: √4 = 2, √9 = 3, ∛8 = 2 (these simplify to rationals)

### Properties:
- √a × √b = √(ab)
- √a ÷ √b = √(a/b)
- (√a)² = a

---

## 14.2 Simplifying Surds

To simplify, find perfect square factors.

### Example 14.1: Basic Simplification
#### Problem
Simplify √48

#### Solution
Find perfect square factor:
48 = 16 × 3

√48 = √(16 × 3)
    = √16 × √3
    = **4√3**

### Example 14.2: Larger Numbers
#### Problem
Simplify √180

#### Solution
180 = 36 × 5

√180 = √(36 × 5)
     = √36 × √5
     = **6√5**

### Example 14.3: Multiple Surds
#### Problem
Simplify √72 + √32

#### Solution
√72 = √(36 × 2) = 6√2
√32 = √(16 × 2) = 4√2

√72 + √32 = 6√2 + 4√2 = **10√2**

## 14.3 Addition and Subtraction of Surds

Only like surds (same radicand) can be combined.

### Example 14.4: Adding Like Surds
#### Problem
Simplify 3√5 + 7√5

#### Solution
3√5 + 7√5 = (3 + 7)√5 = **10√5**

### Example 14.5: Simplify Then Combine
#### Problem
Simplify 2√27 - √75 + √12

#### Solution
Simplify each term:
- 2√27 = 2√(9 × 3) = 2 × 3√3 = 6√3
- √75 = √(25 × 3) = 5√3
- √12 = √(4 × 3) = 2√3

Combine:
6√3 - 5√3 + 2√3 = (6 - 5 + 2)√3 = **3√3**

## 14.4 Multiplication of Surds

### Example 14.6: Multiplying Surds
#### Problem
Simplify √6 × √15

#### Solution
√6 × √15 = √(6 × 15)
         = √90
         = √(9 × 10)
         = **3√10**

### Example 14.7: With Coefficients
#### Problem
Simplify 3√2 × 4√6

#### Solution
3√2 × 4√6 = (3 × 4) × (√2 × √6)
          = 12 × √12
          = 12 × √(4 × 3)
          = 12 × 2√3
          = **24√3**

### Example 14.8: Expanding Brackets
#### Problem
Expand (2 + √3)(5 - √3)

#### Solution
= 2(5) + 2(-√3) + √3(5) + √3(-√3)
= 10 - 2√3 + 5√3 - 3
= 10 - 3 + (-2√3 + 5√3)
= **7 + 3√3**

## 14.5 Division of Surds

### Example 14.9: Simple Division
#### Problem
Simplify $$\frac{\sqrt{50}}{\sqrt{2}}$$

#### Solution
$$\frac{\sqrt{50}}{\sqrt{2}} = \sqrt{\frac{50}{2}} = \sqrt{25} = \mathbf{5}$$

### Example 14.10: Simplify Quotient
#### Problem
Simplify $$\frac{6\sqrt{15}}{2\sqrt{5}}$$

#### Solution
$$\frac{6\sqrt{15}}{2\sqrt{5}} = \frac{6}{2} \times \sqrt{\frac{15}{5}}$$
$$= 3\sqrt{3} = \mathbf{3\sqrt{3}}$$

## 14.6 Rationalizing the Denominator

**Rationalizing** means eliminating surds from the denominator.

### Method 1: Single Surd Denominator
Multiply by the surd.

### Example 14.11: Simple Rationalization
#### Problem
Rationalize $$\frac{6}{\sqrt{3}}$$

#### Solution
$$\frac{6}{\sqrt{3}} \times \frac{\sqrt{3}}{\sqrt{3}}$$
$$= \frac{6\sqrt{3}}{3}$$
$$= \mathbf{2\sqrt{3}}$$

### Method 2: Binomial Denominator
Use the conjugate: (a + √b) → (a - √b)

### Example 14.12: Conjugate Method
#### Problem
Rationalize $$\frac{4}{2 + \sqrt{3}}$$

#### Solution
Conjugate of (2 + √3) is (2 - √3)

$$\frac{4}{2 + \sqrt{3}} \times \frac{2 - \sqrt{3}}{2 - \sqrt{3}}$$

$$= \frac{4(2 - \sqrt{3})}{(2)^2 - (\sqrt{3})^2}$$

$$= \frac{8 - 4\sqrt{3}}{4 - 3}$$

$$= \frac{8 - 4\sqrt{3}}{1}$$

$$= \mathbf{8 - 4\sqrt{3}}$$

### Example 14.13: Complex Rationalization
#### Problem
Rationalize $$\frac{3 + \sqrt{2}}{5 - \sqrt{2}}$$

#### Solution
$$\frac{3 + \sqrt{2}}{5 - \sqrt{2}} \times \frac{5 + \sqrt{2}}{5 + \sqrt{2}}$$

Numerator: $(3 + \sqrt{2})(5 + \sqrt{2}) = 15 + 3\sqrt{2} + 5\sqrt{2} + 2 = 17 + 8\sqrt{2}$

Denominator: $(5 - \sqrt{2})(5 + \sqrt{2}) = 25 - 2 = 23$

$$= \mathbf{\frac{17 + 8\sqrt{2}}{23}}$$

## 14.7 Solving Equations with Surds

### Example 14.14: Square Both Sides
#### Problem
Solve √(x + 3) = 5

#### Solution
Square both sides:
x + 3 = 25
x = 22

Check: √(22 + 3) = √25 = 5 ✓

**x = 22**

### Example 14.15: Surd on One Side
#### Problem
Solve √(2x - 1) = x - 2

#### Solution
Square both sides:
2x - 1 = (x - 2)²
2x - 1 = x² - 4x + 4
0 = x² - 6x + 5
0 = (x - 1)(x - 5)
x = 1 or x = 5

Check x = 1: √(2(1) - 1) = √1 = 1, but 1 - 2 = -1 ✗
Check x = 5: √(2(5) - 1) = √9 = 3, and 5 - 2 = 3 ✓

**x = 5**

## 14.8 Comparison of Surds

### Example 14.16: Comparing Surds
#### Problem
Which is larger: 3√5 or 5√2?

#### Solution
Square each:
$(3\sqrt{5})^2 = 9 \times 5 = 45$
$(5\sqrt{2})^2 = 25 \times 2 = 50$

Since 50 > 45:
**5√2 is larger**
