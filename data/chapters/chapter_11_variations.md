# Chapter 11: Variations

## 11.1 Introduction to Variation

**Variation** describes how one quantity changes in relation to another.

Types of variation:
- **Direct Variation**: Variables increase or decrease together
- **Inverse Variation**: One increases as the other decreases
- **Joint Variation**: Depends on two or more variables
- **Partial Variation**: Combination of constant and varying parts

---

## 11.2 Direct Variation

If y varies directly as x, then:
$$y \propto x$$
$$y = kx$$

where k is the **constant of variation** (or proportionality).

### Example 11.1: Finding the Constant
#### Problem
If y varies directly as x, and y = 15 when x = 5, find (a) the constant k, (b) y when x = 8.

#### Solution
(a) Since y ∝ x, we have y = kx
    15 = k(5)
    **k = 3**

(b) y = 3x = 3(8) = **24**

### Example 11.2: Direct Variation with Powers
#### Problem
y varies directly as x². If y = 50 when x = 5, find y when x = 3.

#### Solution
y ∝ x², so y = kx²

Find k:
50 = k(5)²
50 = 25k
k = 2

Find y when x = 3:
y = 2(3)² = 2(9) = **18**

## 11.3 Inverse Variation

If y varies inversely as x, then:
$$y \propto \frac{1}{x}$$
$$y = \frac{k}{x}$$

### Example 11.3: Inverse Variation
#### Problem
y varies inversely as x. If y = 6 when x = 4, find y when x = 8.

#### Solution
$$y = \frac{k}{x}$$

Find k:
$$6 = \frac{k}{4}$$
k = 24

Find y when x = 8:
$$y = \frac{24}{8} = \mathbf{3}$$

### Example 11.4: Inverse Variation with Square
#### Problem
The pressure P of a gas varies inversely as its volume V. If P = 100 when V = 5, find P when V = 20.

#### Solution
$$P = \frac{k}{V}$$

Find k:
$$100 = \frac{k}{5}$$
k = 500

Find P when V = 20:
$$P = \frac{500}{20} = \mathbf{25}$$

## 11.4 Joint Variation

If z varies jointly as x and y:
$$z \propto xy$$
$$z = kxy$$

### Example 11.5: Joint Variation
#### Problem
z varies jointly as x and y. If z = 60 when x = 3 and y = 4, find z when x = 5 and y = 6.

#### Solution
z = kxy

Find k:
60 = k(3)(4)
60 = 12k
k = 5

Find z:
z = 5(5)(6) = **150**

### Example 11.6: Combined Variation
#### Problem
P varies directly as q² and inversely as r. If P = 18 when q = 3 and r = 2, find P when q = 4 and r = 8.

#### Solution
$$P = \frac{kq^2}{r}$$

Find k:
$$18 = \frac{k(3)^2}{2} = \frac{9k}{2}$$
36 = 9k
k = 4

Find P:
$$P = \frac{4(4)^2}{8} = \frac{64}{8} = \mathbf{8}$$

## 11.5 Partial Variation

If y partly varies as x and partly constant:
$$y = kx + c$$

where k and c are constants.

### Example 11.7: Partial Variation
#### Problem
y is partly constant and partly varies as x. When x = 2, y = 11 and when x = 5, y = 23. Find the formula connecting y and x, and find y when x = 7.

#### Solution
Let y = kx + c

Using x = 2, y = 11:
11 = 2k + c ... (1)

Using x = 5, y = 23:
23 = 5k + c ... (2)

Subtract (1) from (2):
12 = 3k
k = 4

Substitute in (1):
11 = 2(4) + c
11 = 8 + c
c = 3

Formula: **y = 4x + 3**

When x = 7:
y = 4(7) + 3 = 28 + 3 = **31**

### Example 11.8: Taxi Fare Problem
#### Problem
A taxi fare F is partly constant and partly varies as the distance d travelled. For 5 km, the fare is GH₵15. For 12 km, the fare is GH₵36. Find the fare for 8 km.

#### Solution
F = kd + c

For d = 5, F = 15:
15 = 5k + c ... (1)

For d = 12, F = 36:
36 = 12k + c ... (2)

Subtract (1) from (2):
21 = 7k
k = 3

From (1): 15 = 5(3) + c
c = 0

Formula: F = 3d

For d = 8:
F = 3(8) = **GH₵24**

## 11.6 Applications of Variation

### Example 11.9: Speed and Time
#### Problem
The time t to travel a fixed distance varies inversely as the speed s. If it takes 4 hours at 60 km/h, how long does it take at 80 km/h?

#### Solution
$$t = \frac{k}{s}$$

Find k:
$$4 = \frac{k}{60}$$
k = 240

Find t when s = 80:
$$t = \frac{240}{80} = \mathbf{3 \text{ hours}}$$

### Example 11.10: Gravitational Force
#### Problem
The gravitational force F between two objects varies inversely as the square of the distance d between them. If F = 100 units when d = 2 m, find F when d = 5 m.

#### Solution
$$F = \frac{k}{d^2}$$

Find k:
$$100 = \frac{k}{(2)^2} = \frac{k}{4}$$
k = 400

Find F when d = 5:
$$F = \frac{400}{(5)^2} = \frac{400}{25} = \mathbf{16 \text{ units}}$$

## 11.7 Percentage Change in Variation

### Example 11.11: Effect on Variation
#### Problem
If y varies directly as x², what happens to y when x is doubled?

#### Solution
y = kx²

Let original values be y₁ and x.
y₁ = kx²

When x is doubled (becomes 2x):
y₂ = k(2x)² = k(4x²) = 4kx² = 4y₁

**y becomes 4 times its original value (increases by 300%)**

### Example 11.12: Inverse Variation Change
#### Problem
y varies inversely as x. If x increases by 50%, find the percentage change in y.

#### Solution
Let y = k/x

Original: y₁ = k/x

After 50% increase: x₂ = 1.5x
$$y_2 = \frac{k}{1.5x} = \frac{k}{x} \times \frac{1}{1.5} = \frac{y_1}{1.5} = \frac{2}{3}y_1$$

Change = y₂ - y₁ = (2/3)y₁ - y₁ = -1/3 y₁

**y decreases by 33⅓%**
