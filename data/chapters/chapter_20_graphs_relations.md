# Chapter 20: Graphs of Relations and Functions

## 20.1 Introduction to Relations and Functions

A **relation** is a set of ordered pairs (x, y).

A **function** is a relation where each input (x) has exactly one output (y).

### Function Notation:
f(x) reads "f of x" — the output when x is the input.

---

## 20.2 Linear Functions

**Form**: f(x) = mx + c or y = mx + c

- m = gradient (slope)
- c = y-intercept

### Example 20.1: Plotting a Linear Function
#### Problem
Draw the graph of y = 2x + 1 for -2 ≤ x ≤ 3.

![Linear Graph](www/images/chapter_20/linear_graph.svg)

#### Solution
Create a table of values:

| x | -2 | -1 | 0 | 1 | 2 | 3 |
|---|----|----|---|---|---|---|
| y | -3 | -1 | 1 | 3 | 5 | 7 |

Plot points and draw a straight line.

The line has:
- Gradient = 2
- y-intercept = 1

## 20.3 Quadratic Functions

**Form**: f(x) = ax² + bx + c

The graph is a **parabola**:
- a > 0: opens upward (U-shape)
- a < 0: opens downward (∩-shape)

### Key Features:
- **Vertex**: turning point at x = -b/(2a)
- **Axis of symmetry**: x = -b/(2a)
- **y-intercept**: (0, c)
- **x-intercepts**: where y = 0 (roots)

### Example 20.2: Quadratic Graph
#### Problem
Draw y = x² - 4x + 3 for 0 ≤ x ≤ 4.

![Quadratic Graph](www/images/chapter_20/quadratic_graph.svg)

#### Solution
Table of values:

| x | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| y | 3 | 0 | -1 | 0 | 3 |

Key features:
- Opens upward (a = 1 > 0)
- Vertex at x = -(-4)/(2×1) = 2, y = -1
- Vertex: (2, -1)
- y-intercept: (0, 3)
- x-intercepts: (1, 0) and (3, 0)

## 20.4 Solving Equations Graphically

### Example 20.3: Linear Equation
#### Problem
Solve 3x - 6 = 0 graphically.

#### Solution
Draw y = 3x - 6
Find where the line crosses the x-axis.
At y = 0: 3x - 6 = 0, so x = 2

**Solution: x = 2**

### Example 20.4: Quadratic Equation
#### Problem
Solve x² - 2x - 3 = 0 graphically.

#### Solution
Draw y = x² - 2x - 3
Find x-intercepts (where y = 0).

From the graph, the curve crosses at x = -1 and x = 3.

**Solutions: x = -1, x = 3**

## 20.5 Simultaneous Equations Graphically

The solution is the point of intersection.

### Example 20.5: Two Linear Equations
#### Problem
Solve graphically:
y = x + 1
y = -2x + 4

![Simultaneous Equations](www/images/chapter_20/simultaneous_equations.svg)

#### Solution
| x | 0 | 1 | 2 |
|---|---|---|---|
| y = x + 1 | 1 | 2 | 3 |
| y = -2x + 4 | 4 | 2 | 0 |

The lines intersect at **(1, 2)**

### Example 20.6: Linear and Quadratic
#### Problem
Find graphically where y = x² and y = 2x + 3 intersect.

#### Solution
| x | -2 | -1 | 0 | 1 | 2 | 3 |
|---|----|----|---|---|---|---|
| y = x² | 4 | 1 | 0 | 1 | 4 | 9 |
| y = 2x + 3 | -1 | 1 | 3 | 5 | 7 | 9 |

From graph, intersections at **(-1, 1)** and **(3, 9)**

## 20.6 Cubic Functions

**Form**: f(x) = ax³ + bx² + cx + d

### Example 20.7: Cubic Graph
#### Problem
Sketch y = x³ - 3x for -2 ≤ x ≤ 2.

#### Solution
| x | -2 | -1 | 0 | 1 | 2 |
|---|----|----|----|---|---|
| y | -2 | 2 | 0 | -2 | 2 |

The curve has:
- Turning points at x = 1 and x = -1
- y-intercept at origin
- x-intercepts at x = 0, x = √3, x = -√3

---

## 20.7 Reciprocal Functions

**Form**: y = k/x where k ≠ 0

Graph is a **hyperbola** with asymptotes at x = 0 and y = 0.

### Example 20.8: Reciprocal Graph
#### Problem
Sketch y = 6/x

#### Solution
| x | -6 | -3 | -2 | -1 | 1 | 2 | 3 | 6 |
|---|----|----|----|----|----|---|---|---|
| y | -1 | -2 | -3 | -6 | 6 | 3 | 2 | 1 |

Two branches in quadrants I and III.

---

## 20.8 Exponential Functions

**Form**: y = aˣ or y = a^x

### Properties:
- Always positive
- Passes through (0, 1)
- If a > 1: increasing (growth)
- If 0 < a < 1: decreasing (decay)

### Example 20.9: Exponential Growth
#### Problem
Sketch y = 2^x for -3 ≤ x ≤ 3.

#### Solution
| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
|---|----|----|----|---|---|---|---|
| y | 0.125 | 0.25 | 0.5 | 1 | 2 | 4 | 8 |

The curve:
- Approaches but never touches y = 0
- Increases rapidly for positive x
- Passes through (0, 1)

---

## 20.9 Finding Maximum and Minimum

### Example 20.10: Maximum from Graph
#### Problem
The graph of y = -x² + 4x + 5 is drawn. Find the maximum value and where it occurs.

#### Solution
Vertex x-coordinate: x = -4/(2×-1) = 2
At x = 2: y = -(2)² + 4(2) + 5 = -4 + 8 + 5 = 9

**Maximum value is 9 at x = 2**

### Example 20.11: Practical Maximum
#### Problem
A ball is thrown upward. Its height h meters after t seconds is h = 20t - 5t². Find the maximum height.

#### Solution
This is a parabola opening downward.
Vertex at t = -20/(2×-5) = 2 seconds

Maximum height: h = 20(2) - 5(2)² = 40 - 20 = **20 meters**

---

## 20.10 Gradient from Graph

The gradient at a point on a curve is the gradient of the tangent at that point.

### Example 20.12: Estimating Gradient
#### Problem
From the graph of y = x², estimate the gradient at x = 3.

#### Solution
Draw a tangent at x = 3 (where y = 9).
Pick two points on the tangent, e.g., (2, 5) and (4, 13).

Gradient = (13 - 5)/(4 - 2) = 8/2 = **4**

(Actual gradient from calculus: 2x = 6 at x = 3)
