# Chapter 6: Algebraic Expressions

## 6.1 Introduction to Algebraic Expressions

An **algebraic expression** is a mathematical phrase containing:
- Variables (letters like x, y, a, b)
- Constants (numbers)
- Operations (+, -, ×, ÷)

**Terms** are parts of an expression separated by + or - signs.

### Types of Expressions
- **Monomial**: One term (e.g., 3x², 5ab)
- **Binomial**: Two terms (e.g., 2x + 3, a² - b)
- **Trinomial**: Three terms (e.g., x² + 2x + 1)
- **Polynomial**: Many terms

---

## 6.2 Simplifying Algebraic Expressions

Simplify by combining **like terms** (terms with the same variables and powers).

### Example 6.1: Combining Like Terms
#### Problem
Simplify 3x + 5y - 2x + 4y

#### Solution
Group like terms:
= (3x - 2x) + (5y + 4y)
= **x + 9y**

### Example 6.2: Simplifying with Powers
#### Problem
Simplify 4a²b - 2ab² + 3a²b + 5ab²

#### Solution
Group like terms:
= (4a²b + 3a²b) + (-2ab² + 5ab²)
= **7a²b + 3ab²**

---

## 6.3 Multiplication of Algebraic Expressions

### Multiplying Monomials
Multiply coefficients and add exponents of like bases.

### Example 6.3: Multiplying Monomials
#### Problem
Simplify (3x²y)(4xy³)

#### Solution
= 3 × 4 × x² × x × y × y³
= 12 × x³ × y⁴
= **12x³y⁴**

### Multiplying a Polynomial by a Monomial
Use the distributive property: a(b + c) = ab + ac

### Example 6.4: Monomial × Polynomial
#### Problem
Expand 2x(3x² - 4x + 5)

#### Solution
= 2x × 3x² - 2x × 4x + 2x × 5
= **6x³ - 8x² + 10x**

---

## 6.4 Expansion of Binomial Products

To multiply two binomials, use FOIL: First, Outer, Inner, Last

### Example 6.5: FOIL Method
#### Problem
Expand (x + 3)(x + 5)

#### Solution
= x·x + x·5 + 3·x + 3·5
= x² + 5x + 3x + 15
= **x² + 8x + 15**

### Example 6.6: Difference of Signs
#### Problem
Expand (2x - 3)(x + 4)

#### Solution
= 2x·x + 2x·4 + (-3)·x + (-3)·4
= 2x² + 8x - 3x - 12
= **2x² + 5x - 12**

---

## 6.5 Special Products

### Perfect Square Trinomial
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²

### Example 6.7: Perfect Square
#### Problem
Expand (3x + 2)²

#### Solution
Using (a + b)² = a² + 2ab + b²:
= (3x)² + 2(3x)(2) + (2)²
= **9x² + 12x + 4**

### Difference of Squares
(a + b)(a - b) = a² - b²

### Example 6.8: Difference of Squares
#### Problem
Expand (5x + 3)(5x - 3)

#### Solution
Using (a + b)(a - b) = a² - b²:
= (5x)² - (3)²
= **25x² - 9**

---

## 6.6 Factorization by Common Factors

Extract the **Highest Common Factor (HCF)** from all terms.

### Example 6.9: Simple Common Factor
#### Problem
Factorize 6x² + 9x

#### Solution
HCF = 3x
= **3x(2x + 3)**

### Example 6.10: Multiple Variables
#### Problem
Factorize 12a²b - 8ab² + 4ab

#### Solution
HCF = 4ab
= **4ab(3a - 2b + 1)**

---

## 6.7 Factorization by Grouping

When there's no common factor for all terms, group terms and factor each group.

### Example 6.11: Grouping in Pairs
#### Problem
Factorize ax + ay + bx + by

#### Solution
Group: = (ax + ay) + (bx + by)
Factor each group: = a(x + y) + b(x + y)
Factor common binomial: = **(x + y)(a + b)**

### Example 6.12: Four Terms
#### Problem
Factorize 2xy + 6y + 3x + 9

#### Solution
Group: = (2xy + 6y) + (3x + 9)
Factor: = 2y(x + 3) + 3(x + 3)
= **(x + 3)(2y + 3)**

---

## 6.8 Factorization of Quadratic Expressions

To factorize ax² + bx + c, find two numbers that:
- Multiply to give ac
- Add to give b

### Example 6.13: Leading Coefficient = 1
#### Problem
Factorize x² + 7x + 12

#### Solution
Find two numbers that multiply to 12 and add to 7:
3 × 4 = 12 and 3 + 4 = 7

= **(x + 3)(x + 4)**

### Example 6.14: Negative Constant
#### Problem
Factorize x² + 2x - 15

#### Solution
Find two numbers that multiply to -15 and add to 2:
5 × (-3) = -15 and 5 + (-3) = 2

= **(x + 5)(x - 3)**

### Example 6.15: Leading Coefficient ≠ 1
#### Problem
Factorize 2x² + 7x + 3

#### Solution
ac = 2 × 3 = 6
Find two numbers that multiply to 6 and add to 7: 1 and 6

Rewrite: 2x² + x + 6x + 3
Group: = x(2x + 1) + 3(2x + 1)
= **(2x + 1)(x + 3)**

---

## 6.9 Factorization of Difference of Squares

a² - b² = (a + b)(a - b)

### Example 6.16: Simple Difference of Squares
#### Problem
Factorize x² - 49

#### Solution
= x² - 7²
= **(x + 7)(x - 7)**

### Example 6.17: More Complex
#### Problem
Factorize 4x² - 25y²

#### Solution
= (2x)² - (5y)²
= **(2x + 5y)(2x - 5y)**

---

## 6.10 Algebraic Fractions

### Simplifying Fractions
Factorize numerator and denominator, then cancel common factors.

### Example 6.18: Simplifying
#### Problem
Simplify $$\frac{x^2 - 9}{x + 3}$$

#### Solution
$$= \frac{(x+3)(x-3)}{x+3}$$

Cancel (x + 3):
$$= \mathbf{x - 3}$$

### Example 6.19: Addition of Algebraic Fractions
#### Problem
Simplify $$\frac{2}{x+1} + \frac{3}{x-1}$$

#### Solution
LCM = (x + 1)(x - 1)

$$= \frac{2(x-1) + 3(x+1)}{(x+1)(x-1)}$$

$$= \frac{2x - 2 + 3x + 3}{(x+1)(x-1)}$$

$$= \mathbf{\frac{5x + 1}{x^2 - 1}}$$
