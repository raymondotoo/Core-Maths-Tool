# Chapter 8: Linear Inequalities

## 8.1 Introduction to Inequalities

An **inequality** is a mathematical statement that compares two expressions using:
- **<** (less than)
- **>** (greater than)
- **≤** (less than or equal to)
- **≥** (greater than or equal to)
- **≠** (not equal to)

### Example: 
- x > 3 means "x is greater than 3"
- x ≤ 5 means "x is less than or equal to 5"

---

## 8.2 Properties of Inequalities

1. **Addition/Subtraction Property**: Adding or subtracting the same number from both sides preserves the inequality direction.
   - If a > b, then a + c > b + c

2. **Multiplication/Division by Positive Numbers**: The inequality direction is preserved.
   - If a > b and c > 0, then ac > bc

3. **Multiplication/Division by Negative Numbers**: The inequality direction is **reversed**.
   - If a > b and c < 0, then ac < bc

---

## 8.3 Solving Simple Linear Inequalities

### Example 8.1: One-Step Inequality
#### Problem
Solve x + 4 > 7

#### Solution
Subtract 4 from both sides:
x + 4 - 4 > 7 - 4
**x > 3**

### Example 8.2: Multiplication
#### Problem
Solve 3x ≤ 15

#### Solution
Divide both sides by 3:
$$\frac{3x}{3} \leq \frac{15}{3}$$
**x ≤ 5**

### Example 8.3: Dividing by Negative (Reversal)
#### Problem
Solve -2x > 8

#### Solution
Divide both sides by -2 (reverse the sign):
$$\frac{-2x}{-2} < \frac{8}{-2}$$
**x < -4**

---

## 8.4 Multi-Step Inequalities

### Example 8.4: Two-Step Inequality
#### Problem
Solve 2x + 5 < 13

#### Solution
Step 1: Subtract 5 from both sides
2x + 5 - 5 < 13 - 5
2x < 8

Step 2: Divide by 2
**x < 4**

### Example 8.5: Variables on Both Sides
#### Problem
Solve 5x - 3 ≥ 2x + 9

#### Solution
Step 1: Subtract 2x from both sides
3x - 3 ≥ 9

Step 2: Add 3 to both sides
3x ≥ 12

Step 3: Divide by 3
**x ≥ 4**

---

## 8.5 Inequalities with Brackets

### Example 8.6: Expanding Brackets
#### Problem
Solve 3(x - 2) > 12

#### Solution
Step 1: Expand
3x - 6 > 12

Step 2: Add 6
3x > 18

Step 3: Divide by 3
**x > 6**

### Example 8.7: Multiple Brackets
#### Problem
Solve 2(x + 1) - 3(x - 2) ≤ 10

#### Solution
Step 1: Expand
2x + 2 - 3x + 6 ≤ 10

Step 2: Simplify
-x + 8 ≤ 10

Step 3: Subtract 8
-x ≤ 2

Step 4: Multiply by -1 (reverse sign)
**x ≥ -2**

---

## 8.6 Compound Inequalities

A **compound inequality** combines two inequalities.

### Types:
- **Conjunction (AND)**: Both conditions must be true (e.g., 2 < x < 7)
- **Disjunction (OR)**: At least one condition is true (e.g., x < 2 or x > 7)

### Example 8.8: Double Inequality
#### Problem
Solve 3 < 2x + 1 < 9

#### Solution
Solve as two inequalities simultaneously:

Subtract 1 from all parts:
3 - 1 < 2x < 9 - 1
2 < 2x < 8

Divide all parts by 2:
**1 < x < 4**

### Example 8.9: Solving Separately
#### Problem
Solve -1 ≤ 3x - 4 ≤ 8

#### Solution
Add 4 to all parts:
-1 + 4 ≤ 3x ≤ 8 + 4
3 ≤ 3x ≤ 12

Divide all parts by 3:
**1 ≤ x ≤ 4**

## 8.7 Representing Solutions on a Number Line

**Open circle (○)**: Value not included (< or >)
**Closed circle (●)**: Value included (≤ or ≥)

### Example 8.10: Number Line Representation
#### Problem
Represent x ≥ 3 on a number line

#### Solution
```
    ←────────●════════════════════►
            3
```
Closed circle at 3, arrow extending to the right.

### Example 8.11: Compound on Number Line
#### Problem
Represent -2 < x ≤ 4 on a number line

#### Solution
```
    ←───○════════════════●────────►
       -2                 4
```
Open circle at -2, closed circle at 4, line between them.

## 8.8 Inequalities with Fractions

### Example 8.12: Fractional Inequality
#### Problem
Solve $$\frac{x}{3} + 2 > 5$$

#### Solution
Step 1: Subtract 2
$$\frac{x}{3} > 3$$

Step 2: Multiply by 3
**x > 9**

### Example 8.13: Multiple Fractions
#### Problem
Solve $$\frac{x+1}{2} - \frac{x-1}{3} \leq 1$$

#### Solution
LCM = 6. Multiply all terms by 6:
$$3(x+1) - 2(x-1) \leq 6$$
$$3x + 3 - 2x + 2 \leq 6$$
$$x + 5 \leq 6$$
**x ≤ 1**

---

## 8.9 Word Problems with Inequalities

### Example 8.14: Maximum Value Problem
#### Problem
A student needs at least 70 marks to pass. The total is from 3 tests. If the student scored 65 and 72 in the first two tests, what minimum must be scored in the third test to pass?

#### Solution
Let third test score = x
Total = 65 + 72 + x = 137 + x

For passing: 137 + x ≥ 70 × 3
137 + x ≥ 210
x ≥ 73

**The student must score at least 73 marks**

### Example 8.15: Budget Problem
#### Problem
Mr. Kwame has GH₵200 to spend. He buys some items at GH₵15 each. How many items can he buy at most?

#### Solution
Let number of items = n
Cost = 15n

Budget constraint: 15n ≤ 200
$$n \leq \frac{200}{15} = 13.33$$

Since n must be a whole number:
**He can buy at most 13 items**

## 8.10 Solution Sets

### Example 8.16: Integer Solutions
#### Problem
Find all integers satisfying -3 < x ≤ 4

#### Solution
x must be greater than -3 and at most 4.
Integers: **{-2, -1, 0, 1, 2, 3, 4}**

### Example 8.17: Finding Range
#### Problem
If 2x + 3 > 7 and x < 6, find the range of x.

#### Solution
From 2x + 3 > 7:
2x > 4
x > 2

Combined with x < 6:
**2 < x < 6**
