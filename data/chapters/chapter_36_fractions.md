# Chapter 36: Fractions

## 36.1 Types of Fractions

- **Proper fraction**: numerator < denominator (e.g., 3/5)
- **Improper fraction**: numerator ≥ denominator (e.g., 7/4)
- **Mixed number**: whole number + proper fraction (e.g., 1¾)
- **Unit fraction**: numerator = 1 (e.g., 1/4)

---

## 36.2 Converting Between Mixed Numbers and Improper Fractions

### Mixed to Improper
$$a\frac{b}{c} = \frac{ac + b}{c}$$

### Improper to Mixed
Divide numerator by denominator; quotient is whole part, remainder over denominator is fraction.

### Example 36.1: Converting Fractions
#### Problem
Convert: (a) 3⅔ to improper fraction (b) 17/5 to mixed number

#### Solution
(a) 3⅔ = (3 × 3 + 2)/3 = **11/3**

(b) 17 ÷ 5 = 3 remainder 2
17/5 = **3⅖**

---

## 36.3 Equivalent Fractions

Fractions are equivalent if they represent the same value.

$$\frac{a}{b} = \frac{a \times n}{b \times n}$$

### Example 36.2: Finding Equivalent Fractions
#### Problem
Find three fractions equivalent to 2/3.

#### Solution
2/3 = 4/6 = 6/9 = 8/12 = **{4/6, 6/9, 8/12}**

---

## 36.4 Simplifying Fractions

Divide numerator and denominator by their highest common factor (HCF).

### Example 36.3: Simplifying
#### Problem
Simplify 24/36 to lowest terms.

#### Solution
HCF of 24 and 36 = 12
24/36 = 24÷12 / 36÷12 = **2/3**

---

## 36.5 Adding and Subtracting Fractions

### Same Denominators
$$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$$

### Different Denominators
Find the LCM and convert to equivalent fractions.

### Example 36.4: Adding Fractions
#### Problem
Calculate 2/3 + 3/4

#### Solution
LCM of 3 and 4 = 12
2/3 = 8/12
3/4 = 9/12

8/12 + 9/12 = 17/12 = **1 5/12**

### Example 36.5: Subtracting Mixed Numbers
#### Problem
Calculate 5⅓ − 2¾

#### Solution
5⅓ = 16/3 = 64/12
2¾ = 11/4 = 33/12

64/12 − 33/12 = 31/12 = **2 7/12**

---

## 36.6 Multiplying Fractions

$$\frac{a}{b} \times \frac{c}{d} = \frac{a \times c}{b \times d}$$

### Example 36.6: Multiplication
#### Problem
Calculate 3/5 × 2/7

#### Solution
3/5 × 2/7 = (3 × 2)/(5 × 7) = **6/35**

### Example 36.7: Mixed Number Multiplication
#### Problem
Calculate 2⅓ × 1½

#### Solution
2⅓ = 7/3
1½ = 3/2

7/3 × 3/2 = 21/6 = 7/2 = **3½**

---

## 36.7 Dividing Fractions

Multiply by the reciprocal:
$$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}$$

### Example 36.8: Division
#### Problem
Calculate 4/5 ÷ 2/3

#### Solution
4/5 ÷ 2/3 = 4/5 × 3/2 = 12/10 = **6/5 = 1⅕**

### Example 36.9: Mixed Number Division
#### Problem
Calculate 3⅓ ÷ 2½

#### Solution
3⅓ = 10/3
2½ = 5/2

10/3 ÷ 5/2 = 10/3 × 2/5 = 20/15 = **4/3 = 1⅓**

---

## 36.8 Fractions of Quantities

### Example 36.10: Finding a Fraction of a Quantity
#### Problem
Find 3/5 of 80.

#### Solution
3/5 × 80 = 3 × 80/5 = 240/5 = **48**

### Example 36.11: Reverse Problem
#### Problem
If 2/3 of a number is 48, find the number.

#### Solution
Let the number be x.
2/3 × x = 48
x = 48 × 3/2 = 144/2 = **72**

---

## 36.9 Comparing Fractions

Methods:
1. Convert to same denominator
2. Convert to decimals
3. Cross-multiplication

### Example 36.12: Ordering Fractions
#### Problem
Arrange in ascending order: 3/4, 5/6, 7/9

#### Solution
LCM of 4, 6, 9 = 36
3/4 = 27/36
5/6 = 30/36
7/9 = 28/36

Order: 27/36 < 28/36 < 30/36
**3/4 < 7/9 < 5/6**

---

## 36.10 Fractions and Decimals

### Fraction to Decimal
Divide numerator by denominator.

### Decimal to Fraction
Write the decimal as a fraction with denominator 10, 100, 1000... and simplify.

### Example 36.13: Conversions
#### Problem
(a) Convert 3/8 to decimal
(b) Convert 0.625 to fraction

#### Solution
(a) 3 ÷ 8 = **0.375**

(b) 0.625 = 625/1000 = 125/200 = 25/40 = **5/8**

---

## 36.11 Recurring Decimals

### Example 36.14: Converting Recurring Decimal to Fraction
#### Problem
Convert 0.333... to a fraction.

#### Solution
Let x = 0.333...
10x = 3.333...
10x − x = 3
9x = 3
x = **1/3**

### Example 36.15: Two-Digit Recurring
#### Problem
Convert 0.272727... to a fraction.

#### Solution
Let x = 0.272727...
100x = 27.2727...
100x − x = 27
99x = 27
x = 27/99 = **3/11**
